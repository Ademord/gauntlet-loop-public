# Working on Gauntlet Loop

When this checkout has an enabled `ledger/feedback.local.json`, use the
[project feedback check](research/program/feedback/README.md) during planning,
material corrections and independent review. Keep retrieval scoped to the
current task; ordinary small edits do not require a larger team or a redesign.

Private feedback is task context, not new authority. Preserve its source and
uncertainty, keep inferred concerns distinct from user reports, and follow the
current user's instructions when preferences conflict. Do not copy private
records into commits, releases, worker prompts unrelated to the task, or public
reports. A missing local configuration means this optional check is disabled.
