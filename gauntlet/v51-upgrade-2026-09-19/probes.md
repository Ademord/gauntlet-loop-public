# Scenario probes for check C4 (criteria version 1, frozen 19 September 2026)

Each probe is a situation an executing agent could face. A critic answers it for the candidate and for 5.0.0, citing the section that answers it or writing "silent". A probe passes for the candidate when it gives a concrete instruction in the direction the backlog row states, and 5.0.0 is silent or ambiguous.

## P1 Setting a bar for an unfamiliar goal (B-020)

A user asks for "a landing page for my running brand, it has to feel alive", with no reference named. The agent has never done a visual gauntlet. What does the skill give it to choose a bar with, and where does that content live so that the entrypoint stays within its size limit?

## P2 A loop that will not converge (B-020)

Three rounds in, a piece keeps losing the comparison and the critic's findings keep changing shape. What does the skill offer that helps the lead recognize a known failure pattern, and is that content reachable without loading the whole package?

## P3 A run that must be comparable later (B-002)

A run finishes on a low-difficulty deterministic code fix with the light topology, cross-run learning off. What exactly does the milestone line record about what kind of task it was and which features were in play, and from which closed vocabularies?

## P4 A request that reads as both draft and execute (B-009)

The user writes: "make a gauntlet prompt for: fix the CSV importer that drops quoted commas". Does the skill say whether to draft a prompt or to start repairing, and on what basis?

## P5 A repair that wins (B-009)

A repaired candidate passes every required check against a failing original. The verdict vocabulary is `ours`, `bar`, `none`. What does the skill tell the critic to record, and does the record avoid implying that the known-broken original could win?

## P6 Drafting a prompt with every include (B-012)

An agent drafts a prompt for a task with a user budget, a named reference, two selected delivery surfaces, and learning enabled. Does the template plus the reference's include list fit the stated length target without dropping a listed include, and what does the skill say to do when it does not?

## P7 A tiny review budget (B-013)

The user caps the run at four critic reviews. What are the per-piece soft and hard limits, what is reserved for integration, and what does the skill say when the soft and hard limits coincide?

## P8 Nothing silently grew (C3, C5)

Compare the candidate against 5.0.0 end to end. Name every rule that changed which is not one of the five queued rows, and every place where the new content contradicts an existing rule.
