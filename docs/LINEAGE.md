# Gauntlet skill lineage

The active release is [Gauntlet Loop 5.0.0](../skill/SKILL.md), dated 17 September 2026, produced by a gauntlet run on the skill itself with 4.0.0 as the bar. Earlier versions are preserved as history; a historical document's advice does not replace the current release.

## What the evidence establishes

No benchmark or model-performance experiment was run for any version. Each version's evaluation was release review: scenario walkthroughs, consistency checks, and, for v5, independent critics against frozen checks. The research program under `research/program/` states how a performance question would be answered.
